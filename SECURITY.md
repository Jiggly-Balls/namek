# Security Policy

## Supported Versions

The following versions are supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you notice a security issue, please reach out to me via GitHub's [private vulnerability reporting](../../security/advisories/new) for this repo.
You can expect me to respond within 3 business days. When making a report please make sure you are providing the following information:

- A description of the vulnerability and its impact
- Steps to reproduce (or a proof of concept)
- Affected version(s)
- Potential fixes

I'll credit reporters (unless you prefer to stay anonymous) once a fix is released.
